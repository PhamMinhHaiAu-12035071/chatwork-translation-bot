Full Buttons — Combined Effect

Button hover: translate -2px, shadow expands (existing behavior). Icon hover: bounce/slide. Combined = depth + life.

CSS Animation Spec
/* Clay icons — bounce + shine on :hover wrapper */ @keyframes clay-bounce { 0% { transform: scale(1); } 20% { transform: scale(1.22) rotate(-5deg); } 45% { transform: scale(0.9) rotate(3deg); } 65% { transform: scale(1.1) rotate(-2deg); } 100% { transform: scale(1); } } @keyframes shine-sweep { 0% { transform: translateX(-130%) skewX(-15deg); opacity: 0; } 15% { opacity: 1; } 100% { transform: translateX(230%) skewX(-15deg); opacity: 0; } } /* Arrow icons — directional slide */ @keyframes slide-right { 0%,100% { transform: translateX(0); opacity: 1; } 40% { transform: translateX(6px); opacity: 0.5; } 41% { transform: translateX(-8px); opacity: 0; } 100% { transform: translateX(0); opacity: 1; } } /* Close × — wiggle dismiss feel */ @keyframes wiggle { 20% { transform: rotate(12deg) scale(1.1); } 40% { transform: rotate(-10deg); } 80% { transform: rotate(-4deg); } } /* Duration targets: clay ~500ms, stroke ~280-400ms */ /* prefers-reduced-motion: animation: none; */
